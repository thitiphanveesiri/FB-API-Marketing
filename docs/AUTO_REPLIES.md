# แยกข้อความตอบอัตโนมัติของเพจ

**ปัญหา:** ข้อความที่เพจส่งออกทุกอัน (ทักทายอัตโนมัติ, ข้อความนอกเวลา, บอท, หรือคนพิมพ์) ถูกนับเป็น "ตอบแล้ว" ทำให้ SLA ดีเกินจริง
**ทางแก้:** กฎในแท็บ `auto_replies` ของ Google Sheet ข้อความที่ตรงกฎจะถูกติดป้าย **ตอบอัตโนมัติ** และ **ไม่หยุดนาฬิกา SLA / ไม่นับเป็นการตอบ / ไม่ทำให้ลูกค้าเข้าคิว "เงียบ"** กฎใช้กับประวัติทั้งหมดทันที (คำนวณตอนอ่าน) แก้ได้โดยไม่ต้อง deploy

## สร้างแท็บ
เพิ่มแท็บชื่อ `auto_replies` ในชีต แล้วใส่หัวคอลัมน์แถวแรก: `pattern | match | active | note`

| pattern | match | active | note |
|---|---|---|---|
| สวัสดีค่ะ คุณ* ขอบคุณที่ติดต่อ | starts_with | | คำทักทายอัตโนมัติ |
| ขณะนี้อยู่นอกเวลาทำการ | contains | | ข้อความนอกเวลา |
| 123456789012345 | app_id | | บอท (ดูเลข App ID ด้านล่าง) |

- `match`: `contains` (ค่าเริ่มต้น), `exact` (ตรงทั้งข้อความ), `starts_with` (ขึ้นต้นด้วย), `app_id` (ผู้ส่งเป็นแอปนี้)
- `*` = ข้อความที่เปลี่ยนไปได้ (ชื่อลูกค้า เวลา ลิงก์) ใช้ได้ไม่เกิน 3 ตัวต่อกฎ
- ไม่สนตัวพิมพ์เล็กใหญ่ และเว้นวรรคซ้ำ (แต่ไม่ลบเว้นวรรคกลางคำ)
- `active`: เว้นว่าง = ใช้งาน, ใส่ `FALSE` เพื่อปิดชั่วคราว
- กฎที่สั้นเกินไปจะถูกข้ามพร้อมคำเตือนใน "data warnings" (contains ≥ 6 ตัวอักษรจริง, starts_with ≥ 4, exact ≥ 2) เพราะอาจไปตรงกับข้อความที่คนพิมพ์ และข้อความที่ถูกมองว่าอัตโนมัติจะไม่นับเป็นการตอบ
- ข้อความที่เซลล์ส่งจากแอปนี้ (มี `sent_by`) ไม่มีวันถูกนับเป็นอัตโนมัติ และถ้าคอลัมน์ `sender_type` ของข้อความระบุ `human`/`automated` ไว้เอง จะใช้ค่านั้นก่อนกฎ

## หา App ID ของบอทหรือระบบตอบอัตโนมัติ
Webhook เก็บเลข App ID ผู้ส่งของข้อความที่เพจส่ง (echo) ไว้ในคอลัมน์ `sender_app` ของแท็บ `messages` (เก็บตั้งแต่ข้อความใหม่หลังอัปเดต)
1. ให้อีกบัญชีทักเพจเพื่อให้ระบบตอบอัตโนมัติทำงาน แล้วให้เซลล์ตอบเองจากกล่องข้อความของ Business Suite หนึ่งข้อความ
2. ดูใน Inbox: ข้อความที่ไม่ทราบผู้ส่งจะแสดง `(แอป <เลข>)` เปรียบเทียบเลขของข้อความอัตโนมัติกับข้อความที่คนพิมพ์
3. ถ้าเลขต่างกันและเลขของอัตโนมัติคงที่ ใส่เป็นกฎ `app_id` ได้ (แม่นกว่าการจับข้อความ) แต่ **ต้องดูข้อมูลจริงก่อนยืนยัน** ว่าข้อความที่พิมพ์ในกล่องข้อความของเพจไม่ได้มาจากแอปเดียวกัน

## ที่ยังไม่ทำ (ตั้งใจ)
ข้อความที่ไม่ตรงกฎใด ๆ ยังเป็น `unknown` และ **ยังนับเป็นการตอบ** เหมือนเดิม ระบบไม่เดาจากจังหวะเวลาหรืออื่น ๆ
